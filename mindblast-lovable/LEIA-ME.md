# Site Mind Blast (versão para a Lovable)

Site de uma página da Mind Blast Soluções Digitais: sites, apps, sistemas e automação com IA.
Feito em React + Vite + TypeScript + Tailwind, o mesmo formato que a Lovable usa.

## Como o orçamento chega no WhatsApp
O formulário "Peça seu orçamento" monta a mensagem com nome, WhatsApp, empresa, cidade,
o que a pessoa precisa, prazo e detalhes, e abre `wa.me/5511993626555` com tudo já escrito.
A pessoa só toca em enviar. Os botões dos serviços, planos e projetos já marcam a opção certa no formulário.

## Onde editar
- `src/config/site.ts`: número do WhatsApp, e-mail, Instagram, serviços, preços, projetos de exemplo.
- `public/fotos/`: fotos dos cards e das maquetes.

## Rodar no computador
```
npm install
npm run dev
```
